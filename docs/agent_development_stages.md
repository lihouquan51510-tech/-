# AI 选房智能体开发阶段（Stage-Gate）

> 目标：把“需求说明书”落实为可迭代的智能体工程流程。  
> 规则：**每完成一个阶段，必须执行样例数据功能测试；阶段结束必须做 Gate 决策（是否进入下一阶段）。**

## 全部开发阶段

### Stage 0｜范围冻结（Scope Freeze）
- **目标**：锁定城市、站点、字段与 KPI。
- **当前范围**：济南市 + 贝壳租房 + 20 条样例需求。
- **输出物**：范围文档、字段字典、样例集。
- **阶段测试**：验证样例数量=20，关键字段存在。
- **Gate 决策**：是否进入 Stage 1。

### Stage 1｜数据采集（Crawler）
- **目标**：打通抓取链路与兜底机制。
- **输出物**：抓取函数、回退样例、候选列表。
- **阶段测试**：抓取函数返回结果数 > 0（在线或回退均可）。
- **Gate 决策**：是否进入 Stage 2。

### Stage 2｜需求解析（Parser）
- **目标**：将自然语言转结构化约束。
- **输出物**：解析器（预算、户型、区域、偏好、避让项）。
- **阶段测试**：在 20 条样本上统计预算/户型命中率。
- **Gate 决策**：是否进入 Stage 3。

### Stage 3｜匹配与推荐（Filter + Rank）
- **目标**：先硬筛，再可解释打分排序。
- **输出物**：硬筛函数、打分函数、推荐理由。
- **阶段测试**：20 条样本全部可返回推荐结果（Top-K 非空）。
- **Gate 决策**：是否进入 Stage 4。

### Stage 4｜交互展示（UI）
- **目标**：在 Streamlit 展示“解析结果 + 推荐 + 理由 + 执行日志”。
- **输出物**：可演示界面。
- **阶段测试**：手动输入 3 条样例，页面显示阶段日志和推荐理由。
- **截图要求**：通过浏览器截图工具接口生成页面截图（若环境不可用，记录阻塞原因）。
- **Gate 决策**：是否进入 Stage 5。

### Stage 5｜验收与迭代计划（Evaluation）
- **目标**：形成基线报告与下一轮优化 backlog。
- **输出物**：评测报告、问题清单、下一阶段计划。
- **阶段测试**：输出统一报告（通过/失败、指标、阻塞）。
- **Gate 决策**：是否进入下一里程碑（LLM 解析、向量召回、多站点扩展）。

---

## 阶段推进节奏（建议）
1. 运行阶段脚本（`python scripts/stage_gate_runner.py`）
2. 查看阶段报告（`data/stage_gate_report.json`）
3. 与产品负责人确认 Gate
4. 确认后进入下一阶段
